# Screenshots

The root `README.md` embeds four images from this folder. Until they exist, the
README shows broken images — so add them before making the repo public.

| File           | What to capture                                               |
| -------------- | ------------------------------------------------------------- |
| `home.png`     | Home: the companion, today's status, the quick actions.       |
| `plan.png`     | Plan: journey progress, today's allowance, the week ahead.    |
| `progress.png` | Progress: the trend chart, money saved, a recovery milestone. |
| `craving.png`  | The craving sheet, ideally on the breathing guide.            |

Take them on a real device (Expo Go), in **light mode**, with **plausible data**
— a few days of logs, a non-zero savings figure — not an empty first-run state.
An empty app screenshots badly.

Portrait PNGs; a phone-sized capture (roughly 1170×2532) is fine, the README
scales them to 200 px wide.

Nothing personal in frame: no real name in the greeting, no dedication text, no
unlockable companion. Use a throwaway profile.
